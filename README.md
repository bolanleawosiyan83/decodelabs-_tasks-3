Project 1 - Data Cleaning
📌 Project Overview
This project focuses on cleaning and transforming raw data using Power BI Power Query Editor to ensure the dataset is accurate, consistent, and ready for analysis. Data quality is an essential step in every data analysis workflow, and this project demonstrates the techniques used to prepare data for reporting and visualization.

🎯 Project Objectives
Clean and organize raw data.
Improve data quality by removing errors and inconsistencies.
Prepare the dataset for analysis and dashboard creation.
Apply best practices for data transformation in Power BI.

🧹 Data Cleaning Process
The following cleaning steps were performed during this project:

Imported raw dataset into Power BI.
Inspected data quality and identified inconsistencies.
Removed duplicate records.
Removed unnecessary columns.
Renamed columns for better readability.
Corrected incorrect data types.
Handled missing or null values.
Trimmed extra spaces from text fields.
Cleaned non-printable characters.
Filtered unwanted records.
Standardized text formatting.
Created new calculated columns where necessary.
Verified the cleaned dataset before analysis.
